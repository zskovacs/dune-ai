## Review Focus

1. Equal aggregate copies can hide missing or wrong identities: test per-definition
   reconciliation and unknown unique totals in Task 2; actual catalog linkage in Task 3.
2. Empty ability arrays and a working primitive can falsely imply complete cards:
   test face/slot discovery and unmet dependencies in Tasks 2 and 4.
3. Community statements can silently become verified semantics or copied content:
   test claim scope/verification/rights separation in Task 2; evidence review in Task 1.
4. Source-unavailable CI or stale Markdown can give misleading green checks:
   test offline evidence diagnostics and deterministic report staleness in Tasks 2/6.
5. A synthetic terminal episode or restricted leader selection can falsely certify
   a full authentic/training configuration: test fail-closed gates/subsets in Task 5.
