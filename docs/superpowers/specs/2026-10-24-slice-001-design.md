# SLICE-001 design

The user-provided SLICE-001 specification is the authority for this work. Build a
setup-time configuration/composition foundation in the existing Engine library;
keep Toy operational and separate. The first complete-game target is original
Imperium + Rise of Ix + Immortality, competitive 3–4 players. No Dune configuration
in this slice is playable.

Use immutable C# records, typed product/mode/format/category identifiers and
System.Text.Json. Static content metadata is data-driven, sourced and explicitly
incomplete. Separate definitions from future runtime instances. No new package,
project, effect language, gameplay implementation, discovery framework or DI.

Resolve explicit modules once. Module dependencies determine a topological order;
duplicate identifiers, missing dependencies, incompatibilities, cycles and
competing writes fail. Replacements must name the exact prior definition and
depend on its producer. Conditional interaction modules express verified overrides.
Canonical SHA-256 fingerprints cover resolved semantics and metadata versions,
independent of set input order and episode seed. Outputs are immutable and reusable.

Recognize all requested product/mode/format vocabulary; validate only explicitly
researched combinations. Unsupported combinations return actionable diagnostics
and no partial definition. Resolution validates the implemented composition scope,
not completeness of gameplay or card inventories. Eligible leader metadata can be
restricted by explicit IDs; selection policies model fixed/random/sequential/snake
with independent seed, ordered seats and future restriction IDs. No draft execution.

Index all seven local PDFs using 1-based PDF page numbers. Cite every mechanics
claim. Assess community resources and licensing without importing their catalogs
or art. Document gaps and conditional rules, including unsupported formats.

Verification uses focused xUnit coverage, then mise check and smoke. No mandatory
TDD sequencing. No benchmark is needed: no measured hot path is being changed and
no performance claim is made. Preserve existing user edits and supplied PDFs.
